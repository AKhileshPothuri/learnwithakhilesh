## Who This Is For

| Role | Background |
|---|---|
| **Entry-Level GenAI Engineer** | 0–2 years experience; needs theory + code foundations |
| **Mid-Level GenAI Engineer** | 2–5 years; architectural depth, system design, tradeoff reasoning |
| **Forward Deployed Engineer (FDE)** | Customer-facing technical roles; solution design, integration, deployment |

Every chapter ends with **tiered interview questions** at Entry, Mid, and FDE levels — jump straight to those if you're reviewing before an interview, or read the full chapter for depth.

---

## Book Structure

```
Part I   — Foundations          (Neural Networks, Transformers)
Part II  — Large Language Models (Pretraining, Embeddings, Inference)
Part III — Adapting & Aligning  (Prompting, Fine-Tuning, LoRA/QLoRA, RLHF)
Part IV  — GenAI Systems        (RAG, Agents, Evaluation, Deployment)
Part V   — FDE Track            (Customer Scenarios, Integration, Safety)
Appendix — ML Fundamentals Refresher
```

18 chapters. Each chapter: concept explanation → working Python code → "when this comes up at work" → tiered interview Q&A → further reading.

## Run Locally

Install [Quarto](https://quarto.org/docs/get-started/), then:

```bash
git clone https://github.com/AKhileshPothuri/learnwithakhilesh.git
cd learnwithakhilesh
quarto preview
```

This starts a live-reloading local server at `localhost:4200`.
