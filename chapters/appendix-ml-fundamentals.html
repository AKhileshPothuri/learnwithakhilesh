Concept Formula ML Relevance
Bayes theorem \(P(A\|B) = \frac{P(B\|A)P(A)}{P(B)}\) Posterior = likelihood × prior / evidence

B.2.3 Calculus for ML

Concept Formula ML Use
Gradient \(\nabla_\theta L\) — vector of partial derivatives Direction of steepest ascent
Chain rule \(\frac{\partial L}{\partial w} = \frac{\partial L}{\partial z}\frac{\partial z}{\partial w}\) Backpropagation

Optimizer Update Rule Adaptive LR Memory Overhead Best For

B.6 Model Sizing Formulas

Parameters from architecture: \[\text{Params} \approx 12 \cdot n_{layers} \cdot d_{model}^2\] (Accounts for: 4 attention weight matrices of \(d_{model}^2/4\) each, 2 FFN layers of \(4 \cdot d_{model}^2\) each)

Memory for inference (BF16): \[\text{VRAM (GB)} = \frac{\text{Params} \times 2}{10^9}\] (2 bytes per parameter in BF16)

Memory for training (full precision + Adam): \[\text{VRAM (GB)} = \frac{\text{Params} \times 16}{10^9}\] (2 for weights + 2 for gradients + 4 for Adam \(m_t\) + 4 for Adam \(v_t\) + 4 for optimizer fp32 copy)

KV cache per token per layer: \[\text{KV cache per token} = 4 \times d_{model} \times \text{bytes per param}\] (2 for K, 2 for V; each of size \(d_{model}\))

B.12 Interview Q&A: Entry-Level Screening

Q: What is the bias-variance tradeoff?

Bias = systematic error from wrong model assumptions (underfitting). Variance = error from sensitivity to training data fluctuations (overfitting). High-bias example: linear regression on a nonlinear problem. High-variance example: decision tree with no depth limit. Increasing complexity reduces bias but raises variance. The goal is the minimum of bias² + variance + irreducible noise.

Q: When use L1 vs L2 regularization?

L2 (Ridge): shrinks all weights proportionally, rarely to zero. Use for dense feature sets, neural networks (as weight decay). L1 (Lasso): drives weights to exactly zero, producing sparse models. Use for feature selection, high-dimensional sparse data (NLP bag-of-words). Elastic Net combines both when you’re uncertain.

Q: Your model has 95% accuracy on a 95/5 class split. Is it good?

Probably not. A trivial “always predict majority class” baseline achieves 95% accuracy on a 95/5 split. Check: precision = 0, recall = 0, F1 = 0 for the minority class. Use AUC-ROC, F1, or MCC to evaluate imbalanced classifiers, not raw accuracy.

Q: What is cross-validation and when do you use it?

k-fold CV trains on k-1 folds, validates on 1, rotates k times, reports average. Use when: dataset is small (reduces variance of performance estimate), hyperparameter tuning (prevents test set leakage), or when you need confidence intervals on performance. Computationally expensive: k=5 means 5× training runs. For large datasets, a single holdout split is often sufficient.

Q: How does gradient descent work?

Compute gradient of loss with respect to all parameters (backpropagation). Step in the negative gradient direction: θ ← θ - α·∇L. Repeat until convergence. Mini-batch SGD (batches of 32–256) is the standard variant. Adam extends this with adaptive per-parameter learning rates based on first and second moment estimates of the gradient.

(Accounts for: 4 attention weight matrices of $d_{model}^2/4$ each, 2 FFN layers of $4 \cdot d_{model}^2$ each)

**Memory for inference (BF16):**
$$\text{VRAM (GB)} = \frac{\text{Params} \times 2}{10^9}$$
(2 bytes per parameter in BF16)

**Memory for training (full precision + Adam):**
$$\text{VRAM (GB)} = \frac{\text{Params} \times 16}{10^9}$$
(2 for weights + 2 for gradients + 4 for Adam $m_t$ + 4 for Adam $v_t$ + 4 for optimizer fp32 copy)

**KV cache per token per layer:**
$$\text{KV cache per token} = 4 \times d_{model} \times \text{bytes per param}$$
(2 for K, 2 for V; each of size $d_{model}$)

**Quick estimates:**

| Model | Params | BF16 inference | Full train |
|---|---|---|---|
| 7B | 7B | ~14 GB | ~112 GB |
| 13B | 13B | ~26 GB | ~208 GB |
| 70B | 70B | ~140 GB | ~1.1 TB |
| 405B | 405B | ~810 GB | ~6.5 TB |

## Evaluation Metrics Quick Reference

### Classification

| Metric | Formula | Use When |
|---|---|---|
| Accuracy | (TP+TN)/(P+N) | Balanced classes only |
| Precision | TP/(TP+FP) | False positives are costly (spam filter) |
| Recall | TP/(TP+FN) | False negatives are costly (cancer screening) |
| F1 | 2·P·R/(P+R) | Imbalanced; single metric needed |
| AUC-ROC | Area under ROC curve | Ranking quality; threshold-independent |
| MCC | Correlation between predicted/actual | Best single metric for imbalanced |
| Log loss | $-\frac{1}{n}\sum y_i\log\hat{p}_i$ | Probabilistic predictions |

### Regression

| Metric | Formula | Sensitive To |
|---|---|---|
| MAE | $\frac{1}{n}\sum\lvert y_i - \hat{y}_i\rvert$ | All errors equally |
| MSE | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | Large errors (squared) |
| RMSE | $\sqrt{\text{MSE}}$ | Large errors; same units as target |
| R² | $1 - \frac{SS_{res}}{SS_{tot}}$ | Fraction of variance explained |
| MAPE | $\frac{1}{n}\sum\left\lvert\frac{y_i-\hat{y}_i}{y_i}\right\rvert$ | Relative error (undefined if $y_i=0$) |

### Information Retrieval / RAG

| Metric | Formula | What It Measures |
|---|---|---|
| Precision@k | Relevant in top-k / k | Quality of top-k results |
| Recall@k | Relevant found in k / total relevant | Coverage at k |
| MRR | $\frac{1}{\lvert Q\rvert}\sum_q \frac{1}{\text{rank}_q}$ | Rank of first relevant result |
| NDCG@k | Normalized discounted cumulative gain | Graded relevance with position discount |
| Faithfulness | Is answer grounded in context? | RAG hallucination rate |

## Interview Q&A: Entry-Level Screening

**Q: What is the bias-variance tradeoff?**

Bias = systematic error from wrong model assumptions (underfitting). Variance = error from sensitivity to training data fluctuations (overfitting). High-bias example: linear regression on a nonlinear problem. High-variance example: decision tree with no depth limit. Increasing complexity reduces bias but raises variance. The goal is the minimum of bias² + variance + irreducible noise.

---

**Q: When use L1 vs L2 regularization?**

L2 (Ridge): shrinks all weights proportionally, rarely to zero. Use for dense feature sets, neural networks (as weight decay). L1 (Lasso): drives weights to exactly zero, producing sparse models. Use for feature selection, high-dimensional sparse data (NLP bag-of-words). Elastic Net combines both when you're uncertain.

---

**Q: Your model has 95% accuracy on a 95/5 class split. Is it good?**

Probably not. A trivial "always predict majority class" baseline achieves 95% accuracy on a 95/5 split. Check: precision = 0, recall = 0, F1 = 0 for the minority class. Use AUC-ROC, F1, or MCC to evaluate imbalanced classifiers, not raw accuracy.

---

**Q: What is cross-validation and when do you use it?**

k-fold CV trains on k-1 folds, validates on 1, rotates k times, reports average. Use when: dataset is small (reduces variance of performance estimate), hyperparameter tuning (prevents test set leakage), or when you need confidence intervals on performance. Computationally expensive: k=5 means 5× training runs. For large datasets, a single holdout split is often sufficient.

---

**Q: How does gradient descent work?**

Compute gradient of loss with respect to all parameters (backpropagation). Step in the negative gradient direction: θ ← θ - α·∇L. Repeat until convergence. Mini-batch SGD (batches of 32–256) is the standard variant. Adam extends this with adaptive per-parameter learning rates based on first and second moment estimates of the gradient.
